## 功能

- 生成配置保留：生成、返回图鉴、切换物品或重新打开面板后，复用当前游戏会话中该物品上次的编辑配置；列表「生成」也使用这份配置。「重置编辑」恢复原生默认值。现有实物的未应用草稿仍在关闭时丢弃。
- 自定义物品：在图鉴详情页输入配置名称，点击「另存为新配置」。顶部「自定义物品」页支持按保存的配置生成 ×1／×5、重新编辑、改名覆盖、另存和确认删除；同一物品可保存多套配置。模块形状、等级、效果、数值及标签等使用现有生成配置流程保存；仅保存配置，不保存物品身份、库存位置或容器内部物品。
- 自定义配置通过官方文件接口保存到游戏持久数据目录的 `ModData/nicokobo.item-manager/item-presets.json`，跨存档共享并可在重启后读取。未加载对应 Mod 的配置保留在列表中，生成和编辑暂不可用。2026-11-02 已安装版本号仍为 1.3.4 的配置保留与自定义物品构建；本轮 1.3.5 新增液体选项尚未更新游戏内安装，未进行原生界面及跨进程测试。
- 右键背包或自己桌面的自有物品并选择「物品管理」，也可悬停后按 End。编辑当前状态的独立草稿后，点击「应用修改」将单价、专用字段和标签的改动写回原物品。属性修改作用于整叠，关闭或取消会丢弃未应用的草稿。形状与所有权暂不可编辑。
- 复制现有物品：在实物编辑页输入 1 至当前整叠数量，点击「复制指定数量」，或直接「复制整叠」。副本保留当前标签、鉴定特征、价值、文字及外观，使用独立身份和工厂窗口；可选择桌面优先或仅背包，并遵守原生接收与堆叠规则。复制不应用编辑草稿，非空容器须先取空；放不下时释放未交付副本。
- 删除现有物品：可输入数量删除或选择删除整叠，均须确认名称与数量。非空容器须先取空；装备、容器内部或机器槽中的物品须先移至背包或自己的桌面。删除仍遵守原生移除限制，并清理空容器窗口；应用与删除随游戏正常保存。
- 物品图鉴：查看图标、ID、当前游戏语言的物品名称、单价和类别。
- 搜索与分类：同时搜索 ID、中英文名及类别标签，支持已加载 Mod 注册的物品。顶部平铺用途合集和下层分类，显示各组物品数量。
- 界面：游戏原生机械主题、Noto Sans 字体和彩色表情图标，采用灰色面板、米白文字和浅色选中态；移除手动重新扫描按钮。
- 原型编辑：编辑字符串、整数、布尔、浮点数（float）和双精度（double）标签，新增或移除标签，设置金属锭纯度。小数支持负数和科学计数法。
- 模块专用编辑：调整性能、效率、质量、等级、单价和双效果；校验效果类型与互斥关系，支持原版模块已有形状切换。
- 液体容器编辑：设置容量（1–50,000 mL）、调整含量、清空或注入液体。保留 12 种混合预设，另提供原生液体成分的 100% 填充，包括纯酒精、酸、碱、梦境／噩梦／葡萄酒萃取液及化学试剂；当前原生液体表合计提供 47 个选项，名称沿用游戏显示名。调整含量保留混合比例；选择预设会清空后调用原生填充接口，按容量重新填满。
- 更多专用编辑：电池、带耐久的工具、护甲、枪械、使用次数与食物，按物品原生状态显示对应字段。
- 食品券生成：为原生基础食品券补齐兑换必需的正版特征，预览和生成使用相同规则；已有真伪特征不覆盖。
- 数值直接编辑：已有且启用的整数、浮点数和双精度参数默认显示在「物品数值」，保留原有类型；已有专用控件的字段不重复显示。
- 标签名称与说明：常见字段按具体物品或原生类型匹配中文／英文名，跟随游戏语言显示；悬停查看双语名称、含义、已核实的单位与原始 tag。
- 实时预览：编辑后同步更新图标、附加图层、占格、基础估值和原生物品说明。预览不分配周目 UID、不触发正式生成入口的许可证回调。
- 独立按钮生成：点击物品只查看和编辑，通过「生成」按钮创建物品，无需配置开关。顶部「生成位置」默认选「桌面优先」，先放自己的桌面，放不下再尝试背包；也可选择只放「背包」。列表和编辑页共用此选择，按物品工厂的默认数量生成，目标无法完整接收时停止。
- 目录读取与控件复用：先显示物品 ID，优先读取可见页，再补齐其余名称与分类；翻页复用列表条目，完整扫描后才允许导出。
- 图鉴导出：Markdown 使用当前语言的表头、名称和类别；JSON 保留中英文名、价值、类别及贴图引用。
- 界面缩放：在模组配置中调整 `UiScale`（0.5–2），窗口、文字、按钮和间距整体等比例缩放。默认 `1` 为设计基准尺寸的 75%，`0.8` 为 60%，`1.33` 约为设计原尺寸；过大时限制在屏幕内，应用配置后生效。

## 专用字段

| 品类 | 可编辑内容 |
| --- | --- |
| 电池 | 电量、容量、输出功率、充满／放空 |
| 带耐久的工具 | 真实／表观耐久、耐久上限、完全修复 |
| 护甲 | 当前／最大护甲、保护、减伤、修复 |
| 枪械 | 品相、基础火力、精度、可靠性，并显示重算后的实际属性 |
| 有使用次数的消耗品 | 剩余／最大次数、补满；原生自动估价随次数刷新 |
| 食物 | 热量；原生带新鲜度状态的物品另有数值和五档新鲜度预设 |

降低容量或上限时会同步限制当前值。生成副本会刷新电池外观、耐久特征、枪械品相与派生属性，保留编辑后的耗尽状态，并为每份物品分别复制标签。

物品详情默认显示对应的专用配置和「物品数值」。已有且启用的整数、浮点数和双精度参数可以直接改值，不必展开高级标签或手动选择类型；没有额外数值的物品不显示该区域。

外层数值与高级标签使用同一份说明：优先匹配具体物品 ID，再按原生功能标签或物品分类匹配。当前覆盖养殖动物及其等位基因／加成、水产、水培种子与原版植物特性、枪械与配件、机器工作量、电源、使用次数、陈化、化学制品、容器温度、换流器、冰箱和食品券等常见字段。例如动物体重标注克，换流器供电费用标注信用点/kJ；同一个后坐力控制 tag 在枪械上表示基础属性，在配件上表示修正。

标签说明最初于 2026-10-30 依据 Build 26284217 的原生 helper、物品工厂和中英文本核对，显示映射保存在 `ItemTagDescriptions.cs`。当前 Build 26317870 的编译和离线检查不代表每个标签已经重新实机验收。未知类型、第三方自定义 tag 或尚未核实的特性保留原键，并提示含义未确认；不只凭英文键名猜测翻译。标签键、存储类型与存档数据保持原样。

编辑小数可输入如 `1.25`、`-0.5` 或 `1e-3`。空值、无效文本、NaN、无穷大和超出对应类型范围的数值会被拒绝。修改后同步更新预览，并应用到随后生成的物品。「高级标签」用于新增、移除、启用或禁用标签，以及修改类型和编辑其他原始标签；无法判断类型的零值也可在这里指定类型。

食品券的面额和四种图案编号按原生整数读取，值为 `0` 时仍可直接编辑。`STAMP_SEAL` 是印章外观索引，允许 `-1`（不显示）或 `0–1`；原生正版面额低于 160 时为 `-1`，达到 160 时为 `0`，不能据此判断真伪。其他图案编号和异常标记也有双语说明，超出图案范围或写错类型的修改会被拒绝。兑换依据 `CATEGORY_GENUINE_STAMP` 的真实状态；基础工厂缺失该特征时，管理器按原生 `PreBuiltItemHelper.CreateStamp` 流程补齐。此前已经生成的缺失特征食品券需要重新生成。

## 快捷键

| 操作 | 说明 |
| --- | --- |
| 右键实物 → 物品管理 | 打开实物编辑页 |
| 悬停实物 + End | 管理背包或自己桌面上的自有物品，可在模组配置的「物品管理快捷键」中改键 |
| 实物编辑页「应用修改」 | 只写回修改字段，保留原物品身份、位置和内部内容 |
| 实物编辑页「复制指定数量／复制整叠」 | 按实物当前状态复制；可选择放置位置，非空容器先取空 |
| 实物编辑页「删除指定数量／删除整叠」 | 确认后删除；非空容器先取空 |
| Home | 打开／关闭面板，可在模组配置中修改 |
| Esc | 返回图鉴，再按一次关闭 |
| 左键／右键条目或点击“编辑” | 打开详情、专用编辑和高级标签，不生成物品 |
| 顶部“生成位置” | 桌面优先（默认，放不下再尝试背包）／只放背包 |
| 列表“生成”按钮 | 按工厂默认数量生成 1 次 |
| 编辑页“生成 ×1／×5”按钮 | 使用当前编辑配置生成 1／5 次 |
| 悬停预览图标 | 查看完整的原生物品说明 |

面板快捷键支持 Ctrl／Alt／Shift 组合，None 可禁用。原型编辑只影响随后生成的新物品。生成的物品随游戏正常保存。

现有物品管理使用中英双语界面。关闭实物编辑页或按 Esc 会丢弃草稿；已应用的修改、已确认的删除不会由关闭窗口撤销。该功能已随 1.3.4 于 2026-11-02 发布到工坊。2026-11-01 已完成 Release 编译、201 项针对性离线检查和当前 Build 26337366 的安全扫描（无额外能力及硬性拒绝项），并用 `Build-Mods.ps1 -Mod nico-item-manager` 打包安装到正式版游戏 `Mods/nico-item-manager`，安装文件逐一核对一致；当时版本号为 1.3.3。本次发布未更新游戏内安装，未进行该功能的游戏内验收。

启用回调不读取游戏语言；自动语言检查在进入店铺后开始，避免 Mod 启用时提前触发 Unity 本地化初始化。玩家反馈的整个游戏变英文及 `Attempting to use an invalid operation handle` 仍需完整异常堆栈确认原因。

## 本地构建

适用于正式版内置 ModLoader，目标游戏版本 0.46D。构建与打包从仓库根目录运行：

```powershell
dotnet build mods/nico-item-manager/NicoItemManager.csproj -c Release -p:NuGetAudit=false
.\Build-Mods.ps1 -Mod nico-item-manager -NoInstall
```

需要安装时去掉 `-NoInstall`，并先退出游戏。包仅包含 manifest、DLL 和必要资源；README 与 change.log 保留本地。

Steam 描述位于 `workshop-description.txt`，按功能和快捷键整理。准备发布资料：

```powershell
.\Publish-Steam.ps1 -Mod nico-item-manager -PrepareOnly -UpdateDescription
```

此命令不登录或上传。1.3.4 已完成 Release 编译、201 项针对性离线检查和安全扫描，并于 2026-11-02 上传工坊；本次未安装到游戏或执行原生测试。生成位置与启动语言读取调整的较早 135 项离线检查记录保留原有验证范围。

此前发布的 1.3.2 基线通过了正式版 Build 26284217 的隔离原生测试：普通审核与逐包 Developer mode、独立中英文菜单语言、标签显示与双语悬停说明、数值编辑、独立生成及跨进程保存重载。中英文保存各 429 项通过、1 项可选未测，读档各 380 项通过；详细范围与证据见Git 历史。输入拦截的全部组合和实际性能未完成专项验收。扫描按耗时预算分帧推进，后台预算约 2 毫秒，打开面板时约 6 毫秒；单个物品工厂调用无法中途暂停，可能超过预算。实际扫描耗时和帧数可在 F8 日志中查看。
