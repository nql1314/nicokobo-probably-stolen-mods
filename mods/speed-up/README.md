## 功能

- 对话加速：打字与句间等待分别可调 1～32 倍，支持瞬间显示。默认打字 4 倍、句间等待 1 倍。
- 动画加速：进店／开门与离店／关门分别可调 1～8 倍，默认均为 3 倍。
- 全局倍速：局内可调 0.5～10 倍。默认关闭，启用后与局部倍率叠加并保留游戏暂停。其他来源改速后会让出控制，重新开关可恢复。
- 便捷调整：支持原速／均衡／快速三档局部预设、一键恢复原速和倍率提示。

## 默认快捷键

| 操作 | 按键 |
| --- | --- |
| 对话加速 0.5 倍 | Alt+= |
| 对话减速 0.5 倍 | Alt+- |
| 动画加速 0.5 倍 | = |
| 动画减速 0.5 倍 | - |
| 恢复全部原速并关闭全局倍速 | Ctrl+Home |
| 轮换原速／均衡／快速局部预设 | Ctrl+F8 |
| 开关全局倍速 | Ctrl+F9 |
| 全局倍率增加 0.5 并开启全局倍速 | Ctrl+PageUp |
| 全局倍率降低 0.5 并开启全局倍速 | Ctrl+PageDown |

动画加减速也支持小键盘 +／-。对话加速到 32 倍后进入瞬显，减速先回到 32 倍。所有快捷键均可修改，填入 None 可取消绑定；仅在局内响应，文字输入、原生改键捕获及捕获完成当帧不响应。
