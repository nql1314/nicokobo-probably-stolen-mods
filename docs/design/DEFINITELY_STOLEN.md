# 肯定是偷的：设计文档

更新：2026-10-29。当前正式版源码／manifest **1.0.0**，Mod ID `nicokobo.definitely_stolen`，入口 `DefinitelyStolen.dll`。需要正式版 NicoKobo Forge 协议 1；游戏依据为 0.46D / Build 26284217。共用规则见[总览](README.md)。

## 定位与玩家循环

提供一条以夜间扒窃获取商品的经营路线。玩家先根据职业、地区、情报和事件选目标，再决定手动操作或自动判定，在重复偷取的收益与暴露风险之间取舍，最后使用原生携带库存带货返店。

完整循环为：获得资格 → 查看当晚三区与事件 → 进入一个地区 → 选择人物、练习或偷取 → 整理实物 → 正常返店或烟幕脱身 → 出售赃物、提高熟练度并承担声望与风声变化。

## 操作、概率与成长

手动模式使用滑块，空格或点击停手；第一次练习免费，6 秒超时判为暴露。每个目标保存自己的区间及随机状态，进行中的区间不被临时配置或升级改写。自动模式仍播放滑动并完成一次既定概率判定。

| 阵营 | 自动基础成功率 | 每级自动成长 | 手动基础成功区 |
| --- | ---: | ---: | ---: |
| 下层 | 75% | 2 个百分点 | 15% |
| 中层／治安 | 65% | 2.5 个百分点 | 10% |
| 游客 | 80% | 2 个百分点 | 20% |
| 上层 | 55% | 3 个百分点 | 5% |

自动成功率先加等级成长、减风声惩罚，限制在 10%–95%；同一目标每成功一次再乘 0.85，警觉目标再减半。手动成功区按 `基础 + 0.015 × 等级 − 0.5 × 风声惩罚` 计算，并按真实实现应用重复成功、警觉和 5%–30% 区间限制。普通模式中暴露总概率为 `(1−成功率)×失手后暴露占比`。

失手后暴露占比以该目标已完成尝试次数增长，乘每级 0.9、惯偷 0.5、地区倍率和当晚事件修正。下层／换乘／上层暴露倍率分别为 0.875／1.215／1.44，稀有倍率为 0.849／0.887／1。具体公式与手动漏判处理见 [TheftRules.cs](../../mods/definitely-stolen/Domain/TheftRules.cs) 和 [TimingRules.cs](../../mods/definitely-stolen/Domain/TimingRules.cs)。

熟练度 0–10 级，经验门槛为 `0、30、75、140、230、350、505、700、940、1235、1600`；每晚行动数随等级为 0–2 级 3 次、3–4 级 4 次、5–6 级 5 次、7–8 级 6 次、9 级 7 次、10 级 9 次。成功、隐蔽失手、暴露及歇夜按现有规则结算风声，目标携带的物品热度继续保存。

风声达到 20／40／70 时成功率惩罚分别为 5／10／20 个百分点；低于 20 不罚。暴露还结算地区声望处罚，下层／换乘／上层基准为 1／2／3；治安与真实存在的目标阵营声望分别处理，游客没有的声望条目不凭空创建。

事件由原生每日事件处理抽取，持续一晚，同区可叠加。同一职业加成先相加再归一化，风险修正相对乘算；原暴露占比 20% 遇临检变为 25%，不是 45%。事件不直接提高候选件数或全局售价。

第一次建立本夜状态时，同时固定三区的事件 ID、规则版本、权重与暴露修正，随后生成九人。白天小偷情报也可能触发这个生成点；此后预览、换区和读档不重抽。旧夜晚不补事件，新夜晚再使用新规则。定义见 [NightEvents.cs](../../mods/definitely-stolen/Domain/NightEvents.cs)。

## 物品状态、情报与脱身

候选保留 UID、真实价值、稀有标记、正权重、电量、液体组分、真伪及鱼性别等受支持状态。随机药液、种子、饲料、DNA 盘、作物、滤芯和金属锭等需要完整状态的物品保存原生图；成功偷取后才交付实际物品。不能在交付时重新随机品质或组分。

普通候选价值达到 100 即归稀有。稀有与普通两侧都存在时，稀有基率为 T1／T2／T3 的 10%／15%／25%，每级加 2 个百分点，再应用地区修正；只有一侧可用时只从可用侧抽取。特殊物品继续采用明确的独立权重，不用目录顺序当作稀有等级。

小偷到店只为已有资格周目提供当天情报。纸条绑定当夜人物及候选 UID，已生成状态不因重载改变；仓满时保留待领取收据。无法准确恢复的旧轻量随机药剂被排除并显示原因，不生成替代样本。

原版烟雾弹 ID `smoke_grenade`，到店小偷每次供货独立按 5% 概率追加一枚，实际摆放遵循原生柜台容量规则；不加入共享杂货掉落池。

旧脱身烟幕弹 ID `nicokobo.definitely_stolen.escape_smoke`，占 1×2、不堆叠、基础价值 120。不再加入供货和掉落候选池；物品注册、资源和已有实例保留。

原版烟雾弹和旧脱身烟幕弹均可自动触发扒窃脱身，必须放在口袋、背包或外出准备网格中；店内存货无效。暴露时消耗一枚，保留当晚全部赃物并停止继续偷取与练习，声望、经验和风声处罚仍执行。成功或未暴露的失败不消耗。原版烟雾弹同时保留原版用途。

原生背包、口袋、地面、容器及返店按钮继续负责携带。第一次实际偷窃才预扣一次外出次数，免费练习、巡视和返店不重复扣。地面遗留物不会自动带回，返店提示交给原生流程。

## 界面与美术

地点卡片使用夜市、换乘区、商业区原有背景；地区内以官方 `StageObject`／`PanelObject` 展示全屏场景、可点击人物及右侧操作栏，原生地面、口袋和背包保留原位。当前资源共 101 张透明立绘、9 张背景，站位与鞋底锚点随资源维护。

摸包客开局、顺手牵羊、惯偷使用各自的菜单图标，规格见[开局图标指南](../STARTING_ICON_STYLE_GUIDE.md)。新增职业立绘从源提示词和统一导出流程生成，不手改生成图集。

Alt+D 保留开发调试面板，可检查等级、风声、行动、NPC、候选、电量和水质等。普通玩家界面不展示内部调试参数。

## 配置与保存

官方设置保留 `ManualDifficultyCoefficient`（0–2）和 `RandomizeSuccessZoneAfterSuccess`（默认开启）。配置只影响后续合格操作，不重写进行中的滑块判定。

官方周目键为 `nicokobo.definitely_stolen:state`，可核验旧键 `nicokobo.definitely_stolen.state`。当前 **schema 5**，保留 schema 1–4 的已有迁移：已生成的目标、UID、情报、随机状态、进行中区间及旧夜晚继续原样使用。

物品和外出库存图使用原生保存节点及内存特征序列化。状态在原生 `SaveGame` 前暂存到 ModData，由正常保存写盘；偷取、返店和领取情报不额外自动保存。复制槽仅在来源 runID 与真实周目一致、目标槽可确认时重绑槽位，不重发奖励。

## 当前状态与待验收

职业、候选快照、六事件、烟幕、schema 5 和场景 UI 均已有源码。README 记录此前 Release 编译和 8,657 项离线检查；场景调整另有打包安装记录，均不能替代当前玩家操作验收。本次整理不重跑这些检查。

待原生验收的可观察行为包括：三区事件与职业展示、手动／自动／超时、免费练习与外出扣次、真实携带和地面遗留、烟幕处罚、同夜保存读档不重抽，以及不同地区的实际收益。新场景的鼠键、人物点击、遮挡和原生库存布局需要现场确认。
