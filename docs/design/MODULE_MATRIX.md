# 机核协议：模组矩阵——设计文档

更新：2026-10-31。当前是[机核协议 / Mechcore Protocol](../../mods/mechcore-protocol/README.md) **1.0.0** 的内部组件；包 ID `nicokobo.mechcore_protocol`，唯一程序集 `MechcoreProtocol.dll`。组件内容与数据 owner `nicokobo.mechcore_protocol.module_matrix` 保留。外部前置仅 Forge（协议 1、固定能力 API 1），食品加工为可选联动；合成、矩阵与机械飞升已同包提供。编译基线为 0.46D / Build 26337366，合包尚未原生验收。共用规则见[总览](README.md)。

## 定位与玩家循环

让机器优化同时取决于材料、模组形状、邻接、持续工作和生产任务。玩家取得模组 → 摆放并转换属性 → 运行机器积累成长 → 根据停机、扩舱与新设备重排；通过可选 K02 升级把基础模组转为稀有品。

当前包含 **19 件物品**：6 件固定、3 件连续、5 件节点、5 件机器专用模组；另有 6 种摆放词缀。S11 定向投影继续隐藏，不计入可取得目录。

## 节点与结算顺序

| 代码 | 节点 | 当前效果 | 尺寸／价值 |
| --- | --- | --- | --- |
| N09 | 性能转换 | 相邻来源性能转为其 50% 效率、25% 质量及等量负性能 | 1×1／130 |
| N10 | 节能转换 | 相邻来源效率转为其 50% 性能、25% 质量及等量负效率 | 1×1／130 |
| N11 | 质量转换 | 相邻来源质量转为等量性能、效率及负质量 | 1×1／130 |
| N12 | 隔离 | 相邻正属性保留 75%，负属性保留 25%；同一来源最多应用一次 | 1×2／130 |
| N16 | 学习加速 | 相邻原生自学习或连续模组单次有效成长翻倍，上限不变，同类不叠加 | 1×2／160 |

先隔离，再转换；每个来源分别取整后累加。同一来源只交给先放入的转换节点，安装顺序写入标签，取出再放入会重新排队。邻接按实际占用格，不能用外接矩形填平缺口。两次原生扩舱成功后立即重算宿主，保留物品坐标和节点顺序；与读档使用同一重算流程，重复计算不叠加临时属性。

这五种固定能力通过 Forge 私有表解析，不加入原版随机词缀目录；原有效果 ID、槽位和参数继续有效。具体定义见 [NodeEffectDefinitions.cs](../../mods/mechcore-protocol-module-matrix/Definitions/NodeEffectDefinitions.cs)。

## 有效工作、闲置与认知涡轮

连续成长读取真实工序完成／有效推进回调，下次工作起生效。工作日记录在物品标签；夜间实际生产队列结清后才检查闲置，无工作的一天回落一步，并保存结算日避免重复衰退。不猜测缺失旧工作日标记之前的历史。

认知涡轮由机械飞升提供，只有当前周目真实拥有、数量为正的 `nicokobo.aug.cybernetic.cognitive_turbo` 才生效，同类不叠加：

- 连续加速／节能总上限 32→48，连续校准 16→24。
- 原生自学习按该件原有上限 ×1.5 向下取整，不改原生上限标签。
- 一次性、高级、超科技增压器真正完成工序后，成长补足至普通单次的 2 倍；与学习节点组合为 4 倍。
- 按使用前快照去重，多批已经取得的成长不再叠加；拒绝加工不成长。
- 失去涡轮后保留已取得成长，停止继续突破普通上限，闲置回落照常。

打印、水培与 DNA 的进度推进可能多次构成有效工作，描述应使用“有效工作推进成长”，不能承诺只按最终出成品一次成长。

## 五种机器模组

| 代码 | 模组／宿主 | 当前规则 | 尺寸／价值 |
| --- | --- | --- | --- |
| S24 | 渗透／净水器 | 每枚额外滤除可处理污染物剩余量的 25%，多枚依次乘算；与基础净水共用当前质量对应的原生总纯度上限，移除量补成等体积水 | 2×2／220 |
| S06 | 自动供水／集水器 | 优先相邻净水器里的容器，再相邻其他容器，使用真实液体转移 | 1×1／160 |
| S25 | 市场追踪／警报系统 | 完好时每晚尝试一次，性能修正 25% 基础概率，写夜间日志 | 2×2／200 |
| S09 | 解码缓存／密码解序器 | 首个缓存模组记录最近成功目标；相同目标速度 ×2，工序结束恢复 | 2×2／220 |
| S26（已停用） | 批量烧制旧物品 | 仅移除批量烧制功能，不再生效、允许新安装或供货；保留工厂与旧档实物 | 1×4／110 |

机器专用模组只进入对应宿主，保持原生准入。S26 的批量烧制与原版熔炉专用补丁已撤下，玻璃回收由材料精炼机加工；原有连续加工和三件连续模组保留。

S24 在基础净水之后按全部水与非水组分计算剩余去污额度，沿用原生万分比纯度单位与污染物下限向下取整。当前纯度已达上限时附加去污为零；各类污染物共用同一额度，不能分别突破。最终实际去污量回给原生计费和工作回调，零去污不扣电、不成长。机器提示、物流终端和此处说明均沿用 `MachinePurifier.GetMaxPurityCap` 对当前质量的上限，不另设 S24 上限。

打印机、水培和 DNA 已有标准机器身份；当前 `MatrixMachines` 也已显式识别蒸发器，不为此添加通用机器标签。蒸发器的完整成长与读档表现仍需按实际路径验收。

## 获取、升级与价格

五个基础固定模组 M01／M02／M03／M04／M06 进入总模组表与一阶模组表，每件相对权重 0.08。高功率、连续、节点和专用模组不加入该拾荒入口。

杰克逊夜店额外抽两个不同品种：先按基础∶稀有侧 2∶1 选档，再档内等概率；功能性属于稀有侧。原生名额和上架容量继续保留。小偷和发明家等追加供货按类别开关及共享总预算筛选，不重复补夜店两件。

合成扩展 K02 可选升级：**任意基础模组／节点 ×2 → 随机稀有模组／节点 ×1**。同种、混搭、跨堆均可；默认稀有池 13 种，排除功能性、特殊核心、损坏品和封顶核心，关闭类别及缺失工厂实时退出。基础电耗 15，效率影响实际扣电；动态配方不占合成扩展的 30 条固定目录。

原生模组／节点价格交由当前游戏决定，矩阵自家商品继续独立定价。旧原生实例只有启用本 Mod 的价格来源标签时才撤销历史差额，保留品质、其他增值及基础价值字段，随后停用该标签，避免重复撤销；没有此标签的实例不改价。基础／稀有／功能性分类和 K02 升级池保留。

## 配置与保存

固定模组、摆放效果、连续模组、节点、机器模组五开关默认开启，修改后重启。关闭类别时仍注册 19 件物品、11 个效果定义及图标，用于读取与显示；停止新掉落、供货、升级产出和效果，保留成长、工作日、衰退日、槽位与安装顺序。

关闭类别不能通过原生邻接节点间接借出属性；临时屏蔽只在计算作用域发生，结束及异常退出后恢复保存值。重新开启恢复该件真实状态，不发替代物。不自动转换 Demo 配置或旧库存图。
