# 开局角色与特性图标规范

适用于正式版 NicoKobo 内容 Mod 的开局专精和起始特性。菜单图标使用低分辨率单色符号，物品图、人物立绘和地点背景继续使用各自的美术规格。

## 原版依据

基线已于 2026-11-02 按正式版 Build **26337366** 复核。当前快照 `output/full-game-2026-11-02-b26337366/` 的 `source.json` 记录构建身份；已核对 `icons_apprentice`、`icons_fence`、`icons_chemist` 为 19×19、可见像素色 #292234，`expert_negotiator`、`awful_negotiator`、`banned_commissary` 为 36×36、可见像素纯白，均为完全不透明的前景像素。

显示逻辑见 NewGameSpecializationUI.cs（本地采集工作区 `output/full-game-2026-11-02-b26337366/code/Assembly-CSharp/NewGameSpecializationUI.cs`）、NewGamePerksUI.cs（本地采集工作区 `output/full-game-2026-11-02-b26337366/code/Assembly-CSharp/NewGamePerksUI.cs`）、NewGameUIElements.cs（本地采集工作区 `output/full-game-2026-11-02-b26337366/code/Assembly-CSharp/NewGameUIElements.cs`） 与 NewGameStyle.cs（本地采集工作区 `output/full-game-2026-11-02-b26337366/code/Assembly-CSharp/NewGameStyle.cs`）。以下尺寸、颜色和缩放行为来自这些原版资源／代码；语义、线宽和留白要求是本项目据此制定的制作约定。

## 两套规格

| 属性 | 开局角色／专精 | 起始特性 |
| --- | --- | --- |
| 新图源画布 | **19×19 px** | **36×36 px** |
| 前景 | 单色 **#292234**，完全不透明 | 单色纯白 **#FFFFFF**，完全不透明 |
| 背景 | 完全透明 | 完全透明 |
| 图形结构 | 一像素阶梯圆徽记，内部一个职业符号 | 一个主要剪影或手势，可加一个简短辅助符号 |
| 留白 | 外圈占19像素画布；内部主体位于约 x/y=4…14 | 主体通常24…26像素，四边至少约4…6像素 |
| 线条 | 外圈1像素，主体1…2像素，整像素台阶 | 主要线条2像素；关键负形至少2像素 |
| 显示 | 64×64像素槽，目标38像素；19像素图按2倍显示为38像素 | 外框64×72，图标布局区域64×64；36像素图按2倍生成72像素图框，留白使主体仍在布局区域内 |
| 状态配色 | 槽位的青色、黄色和选择状态由原版提供 | 类别、锁定与悬停状态由原版提供 |

原版存在32×32等历史特性资源；新增图统一使用36×36，以保持同一组的视觉体量。`FitPixelArt` 只做至少1倍的整数缩放，**不会把大图缩小到目标尺寸**，因此不能直接交付高分辨率插画或任意大小的精灵。

## 配色与透明度

特性 PNG 只保存白色遮罩，由 `NewGameStyle.PerkColor` 染色：正面 `#9CDB73`，负面 `#CC4849`，中性 `#DBA873`，锁定 `#88948A`。不在图中预先涂绿色、红色、金色或灰色，避免颜色相乘后发暗。

所有新图只使用透明与不透明两档 alpha。允许透明镂空表现指缝、硬币内圈、芯片电路和物件结构。禁止半透明边缘、抗锯齿、渐变、投影、发光、材质纹理和立体光照；不把背景色、按钮方框、选中边框、锁头、文字或点数画入图内。纹理使用 `FilterMode.Point`。

## 符号语义

每个图标先表达功能，再考虑装饰。19像素职业符号只保留一个可识别概念；36像素特性可以用一个主体加一个辅助符号。一个系列复用相同的像素尺度、笔画粗细和视觉重心，不把同一个物品插画缩成不同尺寸凑数。

本组定义如下：

| 运行时键 | 对象 | 图形语义 |
| --- | --- | --- |
| `pickpocket` | 摸包客开局 | 圆徽记中的口袋与向上取物符号 |
| `aug-start` | 机械飞升开局 | 圆徽记中的脑机芯片 |
| `streetwise` | 顺手牵羊 | 勾取一枚硬币的手势 |
| `habitual` | 惯偷 | 掌指稳握硬币的熟练手势 |

## 源图与导出

可编辑源图统一放在 [assets/starting-icons](../assets/starting-icons/)，输出路径和两套规格由 [catalog.json](../assets/starting-icons/catalog.json) 指定。SVG 只使用整像素填充矩形和纯色，不使用描边、曲线、字体或外部图片。修改 SVG／目录配置后，从仓库根目录执行：

```powershell
python tools/assets/export-starting-icons.py
```

仅导出一张可使用 `--icon pickpocket`。导出的 PNG 放入对应 Mod 的 `Textures/Paper`，保持运行时键不变。PNG 为生成结果，不直接手修；高分辨率插画生成流程不再作为菜单图标的源。

接入时，开局与特性通过官方 `iconKey` 引用本包精灵，在本包资源通知中将这些精灵设置为 Point 过滤。不要为调整一组图标修改原版全局 UI、其他 Mod 的贴图或整个图集的过滤方式。

## 交付查看

使用原版的64像素槽位、整数缩放和类别染色查看图标；同时与同类型原版符号并排比较。检查实际可见主体、线条及负形是否清楚，画布留白是否相近，选中／锁定状态是否仍由 UI 提供。源尺寸、单色和透明度由导出入口约束；游戏内实际显示应与编译、静态预览分别记录。
