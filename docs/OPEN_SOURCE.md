# 开源准备状态

公开前还有三项待定。

- **源码授权。** 开发技能带有 MIT 许可。正式版源码、工具与仓库整体尚无统一授权声明，需要仓库所有者确定公开范围与许可。
- **资产与文本授权。** 逐项核对 Mod 封面、图标、字体、原版剧情摘录和使用游戏素材绘制的图片，记录来源和适用许可。物品管理器已随项目保存 Twemoji 的许可和声明。
- **公开历史范围。** 旧提交、分支和标签仍可能包含当前树已排除的内容。公开前决定保留哪些历史，并对拟公开的分支、标签与 Git 对象复核凭据和第三方文件。

配置入口见[本地配置](../config/README.md)。编译使用用户从 Steam 安装的游戏程序集。
